# connectplus3-term1app

## Quiz resume

Normal lesson, unit review, and general review entry resumes the saved attempt. Only the explicit Try Again action starts a new attempt. Answering saves the next unanswered index immediately, before the feedback timer, and notifies the Mona portal of the write. Saved account points and other lesson attempts are retained.

Run regression checks with `node resume.test.cjs`.

Runtime release: 2026-10-04. The app script uses a versioned URL to bypass older script caches. Offline installation uses only files actually published in this repository; cache cleanup is restricted to this app's own prefix.
